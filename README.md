## 📖 Про проєкт

**Poltava-AR** — це мобільний застосунок для туристів та мешканців Полтави, який дозволяє навести камеру смартфона на архітектурну чи історичну пам'ятку міста й миттєво отримати історичну довідку про неї. 

Головна особливість застосунку — **повна автономність (Offline-first)**. Усі нейромережі, база ембедінгів та описи об'єктів зберігаються локально на пристрої, що дозволяє користуватися гідом навіть без мобільного інтернету.

---

## ✨ Основні можливості

* **Детекція об'єктів у реальному часі:** виявлення пам'яток у кадрі камери за допомогою легкої моделі **YOLO Nano**.
* **Векторне розпізнавання (Image Retrieval):** вилучення ознак об'єкта через **EfficientNet-Lite0** та порівняння векторів (Cosine Similarity) із локальною базою еталонних зображень.
* **Робота без інтернету:** локальне зберігання даних та векторів (Room / SQLite), швидкий пошук без запитів до зовнішніх серверів.
* **Інтерактивна карта:** відображення локацій пам'яток Полтави та навігація до них.

---

## 🛠 Технологічний стек

* **Мова програмування:** Kotlin (100%)
* **UI:** Jetpack Compose / Android SDK *(уточніть, якщо використовується XML)*
* **Комп'ютерний зір та ML:** 
  * `YOLO Nano` — детекція об'єктів у кадрі
  * `EfficientNet-Lite0` — генерація ембедінгів (feature extraction)
  * TensorFlow Lite / ONNX Runtime *(вкажіть ваш рушій інференсу)*
* **Локальна база даних:** Room (SQLite) + векторний пошук за косинусною подібністю
* **Карти:** Google Maps SDK / OSM *(вкажіть обраний сервіс)*
