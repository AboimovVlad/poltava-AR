# **2\. ОПИС ПРОГРАМНИХ ЗАСОБІВ**

## **2.1. Мова програмування та середовище розробки**

 - Kotlin – це сучасна мова програмування для нативної розробки на мобільній платформі Android. Kotlin створений, як спеціалізована мова програмування для Android, компанією Google на заміну Java. У проекті використовується для побудови інтерфейсу, та розробки бізнес логіки.

 - CameraX API – бібліотека Jetpack для роботи з камерою пристрою, яка забезпечує потокове захоплення кадрів, для передачі їх у модель детекції в реальному часі.

 - Android Studio – основне середовище розробки для мобільних застосунків на ОС Android.

## **2.2. Засоби комп’ютерного зору та штучного інтелекту**

 - YOLO Nano – це легковажна модель детекції об’єктів у кадрі, яка має лише один клас для детекції конкретного об’єкту. У проекті використовується для детекції пам’ятників у кадрі, та малювання рамки на екрані навколо об’єкта детекції.

 - EfficientNet-Lite0 – згорткова нейромережа, яка оптимізована для мобільних пристроїв, що використовується для екстракції виділених об’єктів у векторні ембеддінги.

 - Cosine similarity – математичний метод порівняння векторів на схожість, який допомагає порівняти ембеддінг з бази даних та поточного кадру, для ідентифікації пам’ятника.

## **2.3. Управління даними та локальне середовище**

 - SQLite / Room Persistence Library – локальна реалізація реляційної бази даних, зашита у assets-пакет застосунку. Забезпечує повністю автономну роботу, без потреби Інтернет з’єднання, зберігаючи данні про пам’ятники, аудіо шляхи та бінарні данні векторів для ембеддінгу.

## **2.4. Хмарні середовища та інструменти для навчання ML**

 - Google Colab – хмарне середовище з підтримкою GPU, яке використовувалося для навчання моделей, написання скриптів пакетної обробки зображень, генерації дата сетів та створення попереднього створення файлу бази даних з витягнутими ембеддінгами перед впровадженням у мобільний застосунок.
